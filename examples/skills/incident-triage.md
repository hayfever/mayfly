# Incident triage

Work in this order:

1. State what is failing and who is affected.
2. List the evidence you used. Separate facts from assumptions.
3. Identify the most likely cause and one alternative.
4. Propose the smallest safe mitigation first.
5. List the follow-up work that prevents recurrence.

Write the result to `triage.md` in the workspace. Keep it under one page.
